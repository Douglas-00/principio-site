# Princípio Impresso · Site

Site institucional da Princípio Impresso, loja cristã de design e soluções gráficas: história, produtos por ocasião, propósito, galeria e contato.

## Rodar

```bash
npm install
npm run dev
```

## Ajustes rápidos

- `lib/config.ts`: WhatsApp (só dígitos, com 55 e DDD), Instagram e cidade.
- `app/page.tsx`: textos e lista da galeria.
- `public/images/`: fotos dos produtos (WebP). Para trocar uma foto, mantenha o nome ou atualize a lista em `page.tsx`.
- `app/globals.css`: cores e fontes no topo do arquivo (`:root`).

## Identidade

Cores tiradas das capas: marrom do logo, marinho, mostarda, rosa, menta e fundos creme e pastel. Títulos em Cormorant Garamond, texto em DM Sans, bordas onduladas como nas artes do Instagram.
